# Contributing

These are personal projects, maintained in my spare time.

## Issues

Issues are welcome, for bug reports as well as questions. For security vulnerabilities, follow [SECURITY.md](SECURITY.md) instead.

## Pull requests

Open an issue before a pull request, so we can agree on the change first. Then:

- Keep the pull request small and focused on one change.
- Follow the existing code style of the repository.
- Write commit messages in the [Conventional Commits](https://www.conventionalcommits.org/) format, for example `fix: handle empty input`.
- Make sure CI passes.

## AI assistance

Say in the pull request if the contribution was produced with AI assistance. Only submit code you understand and can explain line by line.
